# 🎨 How to Create Social Media Images for SEO

## Why These Images Are Critical

When someone shares your site on:
- **Facebook/LinkedIn** → Shows Open Graph image (og-image.png)
- **Twitter/X** → Shows Twitter Card image (twitter-card.png)
- **WhatsApp/Telegram** → Shows Open Graph image

Without these images, shares look unprofessional and get fewer clicks!

---

## Required Images

### 1. Open Graph Image
- **Filename:** `og-image.png`
- **Size:** 1200 x 630 pixels
- **Location:** `/src/public/assets/og-image.png`
- **Used by:** Facebook, LinkedIn, WhatsApp, Telegram, Discord

### 2. Twitter Card Image
- **Filename:** `twitter-card.png`
- **Size:** 1200 x 675 pixels (16:9 ratio)
- **Location:** `/src/public/assets/twitter-card.png`
- **Used by:** Twitter/X

---

## Option 1: Use Canva (Easiest - 10 minutes)

### Step-by-Step:

1. **Go to Canva**
   - Visit: https://www.canva.com
   - Sign up for free account (if needed)

2. **Create Open Graph Image (1200x630)**
   - Click "Create a design"
   - Click "Custom size"
   - Enter: Width: 1200, Height: 630
   - Click "Create new design"

3. **Design Your Image**
   
   **Suggested Layout:**
   ```
   ┌─────────────────────────────────────┐
   │                                     │
   │    🖊️  Collaborative Notepad       │
   │                                     │
   │    Real-Time Note Sharing          │
   │    Free • Open Source • No Sign-Up │
   │                                     │
   │    collabnote.link                 │
   │                                     │
   └─────────────────────────────────────┘
   ```

   **What to Include:**
   - App icon/emoji (🖊️ or 📝)
   - App name: "Collaborative Notepad"
   - Tagline: "Real-Time Note Sharing"
   - Key benefits: "Free • Open Source • No Sign-Up"
   - URL: "collabnote.link"

   **Design Tips:**
   - Use your brand color: `#fefae0` (light yellow) as background
   - Use dark text (`#283618` or `#000000`) for contrast
   - Choose clean, modern font (Montserrat, Poppins, or Roboto)
   - Keep text centered and readable
   - Leave margins (100px from edges)
   - Use emojis for visual appeal

4. **Download**
   - Click "Share" → "Download"
   - Format: PNG
   - Quality: Standard
   - Save as: `og-image.png`

5. **Create Twitter Card (1200x675)**
   - In Canva, click "Resize"
   - Enter: Width: 1200, Height: 675
   - Click "Copy & resize"
   - Adjust elements if needed (it will auto-adjust)
   - Download as: `twitter-card.png`

6. **Upload to Your Project**
   - Copy both images to: `/src/public/assets/`
   - Ensure names match:
     - `og-image.png`
     - `twitter-card.png`

## Design Best Practices

### ✅ Do:
- Use high contrast (readable text)
- Include app name prominently
- Add key benefit/tagline
- Include website URL
- Use brand colors
- Keep it simple and clean
- Test on mobile (text should be readable)

### ❌ Don't:
- Use tiny text (minimum 32px)
- Overcrowd with information
- Use low contrast colors
- Forget to include URL
- Use copyrighted images
- Make it too busy/cluttered

## Testing Your Images

After creating, test them:

### Facebook Debugger:
1. Visit: https://developers.facebook.com/tools/debug/
2. Enter: https://collabnote.link
3. Click "Scrape Again"
4. Your og-image.png should appear

### Twitter Card Validator:
1. Visit: https://cards-dev.twitter.com/validator
2. Enter: https://collabnote.link
3. Preview should show twitter-card.png

### LinkedIn Post Inspector:
1. Visit: https://www.linkedin.com/post-inspector/
2. Enter: https://collabnote.link
3. Should show og-image.png
